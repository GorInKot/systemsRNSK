## ЗАДАЧА
Переработка UI страницы. Мы меняем вкладку "Новый сотрудник" на "Администрирование". 

## Общее
Мы оставляем 2 вкладки. Над ними располагаем строку с кнопками "Экспорт JSON", "Импорт JSON". 
Кнопка "Импорт JSON" - загружает в наш сервис данные сотрудника - JSON файл с полями данных конкретного сотрудника. 
Кнопка "Экспорт JSON" - выгружает на устройство файл с данными конкретного сотрудника, если он заполнил заявку на какую-либо систему

## Вкладка "Действующий сотрудник":
Вкладка "Действующий сотрудник" меняется на "Сотрудник" - она должна быть основной. Оставляем текущее расположение - сетку. Меняем расположение типов заявок. Самым первым делаем "Заявка на Учетную Запись". Это отправная точка для сотрудника. Без Учетной Записи (УЗ) сотрудник ничего не сможет сделать. Общая последовательность:
- УЗ (обязательно первым)
- Почта (обязательно вторым)
- ПКЗИ (обязательно вторым)
- VipNet
- КСЭД
- SAP
- 1C
- ВКД
- Терминальный сервер
- Лаборатория ИИ


## Вкладка "Администрирование":
- Создаем кнопки "Импорт данных", "Экспорт" и "Добавить сотрудника". 
- Импорт - добавляем с устройства файл со всеми сотрудниками. Это должен быть JSON. По полям - информация в ниже есть (таблица) 
- Эспорт - выгружает на устройство JSON-файл с обновленной информацией по сотрудникам. 
- "Добавить сотрудника" - сначала делаем импорт (загружаем всех сотрудников в localStorage), потом добавляем нового сотрудника. 
- На экране делаем таблицу под кнопками Импорт данных", "Экспорт" и "Добавить сотрудника". Заголовки таблицы: № п/п, ФИО, Должность, Номер телефона, Email, Наименование структурного подразделения, ФИО руководителя, должность руководителя, номер телефона руководителя, Номер приказа, дата приказа.
