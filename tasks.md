# Задача
- реализовать HTML-сервис по заполнения заявок на доступы к различным системам. 

# Логика программы
- В нашу организацию устраивается новый сотрудник. Ему необходимо оформить доступы к различным системам: создать учетную запись, получить почтовый ящик и т.д.  Систем много, знания все разбросаны по специалистам. Разрабатываемый файл будет лежать на сетевом хранилище, куда каждый сможет, при необходимости, зайти и оформить себе заявки на доступы к системам. Все данные мы будем хранить в отдельном файле в формате JSON. 

# Системы
- Учетная запись
- почтовый ящик
- лаборатория ии
- ЦУС
- ЕКТП
- Терминальный сервер (список дополнится со временем)

# Логика действий сотрудника
- У сотрудника перед глазам есть некий чек-лист с заявками. Он понимает, что у него нет ничего. Первым делом он заполняет данные на создание учетной записи. Он нажимает на кнопку "Учетная запись" - у него открывается модальное окно с полями для заполнения. Он заполняет их, сохраняет, у него автоматически формируется файл с заявкой на учетную запись. И так со всеми заявками. По каждой заявке (что и в каком месте необходимо заполнять - я сообщю позже)
